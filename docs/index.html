Le probleme

Entre deux boxes, tout se melange

Un fichier telecharge au milieu de tes affaires, le .ovpn introuvable, l'IP retapee cent fois, les notes eparpillees. ctf-env colle tout ca au challenge en cours, pour que tu restes sur l'attaque.

Ce qu'il fait

Le rangement se fait pendant que tu bosses

Un challenge range

ctf new htb/box cree notes, fichiers et scans, et le marque en cours.

Telechargements classes

Chaque fichier arrive dans ~/Downloads file dans le challenge, les .ovpn vers le dossier VPN. Avec notification.

VPN en une commande

ctf vpn lance OpenVPN avec ton pack HTB et affiche ton IP. Fini de chercher le fichier.

Tri d'artefacts

Un fichier recu est identifie (exiftool, binwalk, zsteg, tshark...) et classe par categorie : stegano, reverse, forensic, crypto.

Pistes automatiques

ctf scan et ctf log lisent ta recon et poussent des pistes : Basic auth, noms .htb, ports filtres, web a enumerer.

Garde le fil

ctf ip, ctf flag, ctf note : l'IP, les flags et les notes restent dans le challenge, visibles d'un coup d'oeil.

Installer

Un script, et c'est en place

Sur Arch (ou derive). Python 3 suffit ; le reste des outils, tu les as deja presque tous.

curl -fsSL https://raw.githubusercontent.com/Salemgnk/ctf-env/main/install.sh | bash copie, colle, c'est installe

1Recuperer le depot

git clone https://github.com/Salemgnk/ctf-env.git
cd ctf-env

2Lancer le script

./install.sh
  • pose la commande ctf dans le PATH
  • cree les noms impacket-* facon Kali
  • active le service de rangement
  • installe la completion Tab et la fonction cdc
⚠

Ce qu'il touche. ctf-env ecrit seulement dans ~/Documents/ctf, ~/.config/ctf et ~/.cache/ctf. Le VPN demande ton mot de passe sudo ; rien d'autre n'utilise sudo sans te le dire.
